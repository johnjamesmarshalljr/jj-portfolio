# JJ Marshall — Portfolio

React + Vite static site.

## Local dev
```
npm install
npm run dev
```

## Build
```
npm run build
```
Outputs to `dist/`.

## Deploy to Vercel
1. Push this folder to a new GitHub repo.
2. Go to vercel.com → "Add New Project" → import the repo.
3. Vercel auto-detects Vite (build command `npm run build`, output dir `dist`). Click Deploy.

That's it — no environment variables or extra config needed.
